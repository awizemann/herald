## Description

Standards audit 2026-08-18 (04 Swift Conventions §1), Medium. AccountStore.swift:45 uses `private let lock = NSLock()` in the nonisolated `KeychainAccountStore` to guard a read-modify-write of the Keychain account index. The standard prefers an `actor` for shared mutable state (or os_unfair_lock for a bare flag). The RMW guard is legitimate; converting the type to an actor is the standard-preferred shape and removes the manual lock. Verify the nonisolated-protocol conformance still holds for test fakes (see Herald Concurrency Rules) after the change.
