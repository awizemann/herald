## Plan

P3 landed (all six items):
1. MIME: `MIMESniffer.sniff/resolve/normalize` (PDF, ZIP/OOXML, RTF, gzip, OLE, PostScript + images); `attachmentData` sniffs instead of hardcoding octet-stream; `AttachmentFile.filename` appends the resolved extension when missing OR contradicted; save panel proposes the staged name.
2. `Attachment.disposition` (attachment|inline) replaces the `contentID != nil` inference everywhere (`isInline`, `downloadableAttachments`, `MailViewModel.inlineImages`).
3. `CachedMessageBody.attachments` + `MailStore.storeBody/cachedBody`; `MailViewModel.cachedDetail` rebuilds a detail from cache when `GET /messages/{id}` fails (decoding failures exempted so a broken contract still surfaces).
4. Cached-body fallback substitutes `cid:` images; substitution restricted to quoted, case-insensitive `src`/`background` attribute values.
5. Preview: staleness guard reads the CURRENT attachment list; `previewURL` cleared on selection change/disappear; refcounted pin (taken inside the actor) stops eviction under Quick Look / drag / save; inline failures counted and shown as a banner.
6. Save reuses the staged cache (one download) and writes via a sibling temp + replaceItemAt, so a failed save cannot destroy an existing file.
