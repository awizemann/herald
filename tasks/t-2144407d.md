## Description

Consequence: ~60 raw spacing/padding literals across the views, off-grid values (1, 5, 6, 7, 10), and measurable drift (unread dot is 8×8 in ConversationListView:224/361 but 7×7 in ReadingPaneView:85).

2. Migrate the literals. Worst files: ConversationListView (~17), ComposeWindow (~13), ReadingPaneView (~10), SidebarView (~6), SettingsView (~4, incl off-grid spacing:1). AttachmentChip:32 cornerRadius 6.
3. Resolve the 8×8/7×7 dot to one token. Keep structural frames (minWidth/maxWidth:.infinity/window sizing/existing token frames) as-is.

Report: documents/reports/standards-audit-2026-08-18.md. Update the design memory note (conventions/Herald Design System and Accessibility) with the new token scales once added. Do NOT touch Swift source as part of the audit itself — this is the follow-up implementation task.
