MailCommands.swift declares "New Message" ⌘N in CommandGroup(after: .newItem), so SwiftUI's default New Window (also ⌘N) wins and opens another main window showing the Inbox — exactly the report. Fix: CommandGroup(replacing: .newItem) (keep New Window under ⌘⇧N if wanted). Also add a Compose button to the main toolbar (square.and.pencil) — none exists in RootView/SidebarView/ConversationListView.
