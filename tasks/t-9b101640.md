## Description

Pure HeraldKit layer, no UI. Read memory note decisions/Herald AI Classification via Cloudflare AI Gateway first.
- `AIGatewayConfiguration` (accountID, gatewayID, model) Sendable value.
- `AIGatewayClient`: POST https://gateway.ai.cloudflare.com/v1/{account}/{gateway}/compat/chat/completions, header `cf-aig-authorization: Bearer <token>`, explicit User-Agent (Cloudflare 1010 blocks default UAs), temperature 0, JSON body. Model string sent as `workers-ai/<@cf/...>`.
- Token read through existing SecretStore/KeychainStore (new key, e.g. `ai-gateway-token`); never logged.
- `EmailClassifier`: builds system prompt from candidate labels (id, name, description) with explicit "none" option and `/no_think`; user message = From, Subject, body text truncated ~4000 chars; strict parse — tag must match an allowed label name/id else nil. Confidence NOT used.
- Typed errors: unauthorized(401), insufficientCredits(402), modelNotAllowed(403 code 5018), blocked(1010), rateLimited(429), malformed response, transport.
- `testConnection()` minimal call.
- Swift Testing + URLProtocol fake server: headers/URL/body shape, parse success, off-list answer → nil, "none" → nil, prose-wrapped JSON, each error mapping, body truncation.
