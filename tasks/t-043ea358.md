## Description

scripts/release.sh:91 logs `log "Preflight${DRY_RUN:+ (dry run)}"`. DRY_RUN defaults to the string "0" (non-empty), and `${VAR:+...}` expands whenever VAR is set AND non-empty — so the "(dry run)" label prints on EVERY run, including real releases. Cosmetic only: the actual behavior gates are all `[[ $DRY_RUN -eq 1 ]]`, which correctly treat 0 as not-dry-run (verified: v0.2.1 really did notarize + publish). Fix: make the label conditional on the same `-eq 1` test (e.g. `local dr=""; [[ $DRY_RUN -eq 1 ]] && dr=" (dry run)"; log "Preflight$dr"`). Spotted during the v0.2.1 release 2026-08-18.
