Turn 4 · Domain settings: sidebar sections + detail pane Settings follows the mail window's layout: the same account selector, the same drill-down sidebar, and a detail pane on the right. Workflows and future sections slot in as new sidebar items. Every setting is tagged with where it lives: SERVER for the HQBase Mail API, HERALD for this Mac only. From the API spec (Mail API v1): there is no domain endpoint. A domain exists only as mailDomainId on each mailbox address, plus domain-scoped signatures (/signatures/manage, admin only). So a real server-side “Delete domain” needs an upstream HQBase endpoint. Until that exists, it's designed to hand off to the web admin, and Hide from Herald is the local, reversible option.
