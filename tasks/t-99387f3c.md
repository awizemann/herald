## Description

Root cause found (C11, audit-2026-09-19): NotificationsTests.theSettingIsHonouredPerPass waited on `model.status == .idle`, which is already true from the moment the model exists (default state, before `.began` is ever yielded) — the wait resolved without proving the pass had run, so the negative `posted.isEmpty` assertion and the settings flip that followed it both raced the actual event processing. Fix: yield `.began` first and wait for `status == .syncing` before proceeding, so the later wait for `.idle` is evidence the pass consumed the event. Verified stable over 10 sequential `xcodebuild -only-testing:HeraldTests/NewMailWiringTests/theSettingIsHonouredPerPass` runs (10/10 pass).
