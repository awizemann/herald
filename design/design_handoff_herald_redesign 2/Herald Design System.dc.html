Turn 4 · Domain settings: sidebar sections + detail pane Settings follows the mail window's layout: the same account selector, the same drill-down sidebar, and a detail pane on the right. Workflows and future sections slot in as new sidebar items. Every setting is tagged with where it lives: SERVER for the HQBase Mail API, HERALD for this Mac only. From the API spec (Mail API v1): there are no domain endpoints, and the API deliberately leaves out administrative operations. A domain exists only as mailDomainId on each mailbox address, plus domain-scoped signatures (/signatures/manage). Herald never deletes a domain on the server: it hides it locally, or links out to HQBase Admin.

Turn 3 · Thread view A conversation with more than one message drills in the same way the sidebar does. The list column swaps to the thread's messages, and a back link names the folder it came from (⎋ or ⌘[). The reading pane shows the selected message. Rows with a count carry a chevron, and selecting one opens the thread.
