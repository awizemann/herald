## Description

Pre-existing (also on main), made visible by the redesign: every scope lists at most the newest 100 cached conversations (MailStore.conversations default limit 100; nothing pages). With All domains as the default over ~160 mailboxes, the sidebar can say 450 unread while the Inbox shows 100 rows; local search only covers those rows; revealConversation (notification click) fails when the thread isn't in the top 100 of the landing scope. Proposal: load-more on scroll to the end, and have revealConversation fetch the thread's row directly. Needs Alan's go-ahead (behaviour + perf trade-off). Source: redesign A4 audit 2026-09-28.

## Plan

1.0 Phase B (Opus sub-agent, worktree). Lazy pagination: load next page (server cursor) when the list scrolls near its end, per listing; cache stays bounded; no full-mailbox fetch. Tests + real run against local HQBase 1.4.2. Commit on branch `release/paging`.
