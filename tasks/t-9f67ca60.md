## Description

The redesign's folder picker at levels 1–2 is only the list header Menu; there is no Mailbox/View menu-bar item (with shortcuts) to choose a folder or go back a sidebar level, bending the "every action has a menu item" rule for keyboard-only users. Proposal: a Go/Mailbox menu with Inbox/Starred/Sent/Drafts/Archived/Trash (⌘1…⌘6?) and "Back" for the sidebar. Source: redesign A4 audit 2026-09-28.
